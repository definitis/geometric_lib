# Документация библиотеки geometric_lib

Библиотека `geometric_lib` содержит функции для вычисления площадей и периметров четырёх плоских фигур: круга, квадрата, прямоугольника и треугольника. Библиотека написана на стандартном Python 3 и не требует сторонних зависимостей.

## Структура файлов проекта

| Файл | Описание модуля |
| --- | --- |
| `circle.py` | Вычисление площади круга и длины окружности |
| `square.py` | Вычисление площади и периметра квадрата |
| `rectangle.py` | Вычисление площади и периметра прямоугольника |
| `triangle.py` | Вычисление площади и периметра треугольника |
| [api.md](api.md) | Полный справочник функций с типами и формулами |
| [CHANGELOG.md](CHANGELOG.md) | История изменений проекта с хэшами коммитов |

## Ограничения и условия применения

1. Все передаваемые геометрические размеры должны быть положительными числами (`> 0`) в одинаковых единицах измерения.
2. Для треугольника переданные стороны `a`, `b`, `c` должны удовлетворять неравенству треугольника ($a + b > c$, $a + c > b$, $b + c > a$).
3. Проверка корректности переданных аргументов возлагается на вызывающий код.

## Автоматическая проверка примеров (doctest)

Каждая функция содержит в блоке комментариев исполняемый пример. Их можно протестировать с помощью стандартного модуля `doctest`:

```console
python -m doctest -v circle.py square.py rectangle.py triangle.py
```

При корректной работе все 8 тестов (по 2 на модуль) завершаются со статусом `ok`.
