# Справочник API библиотеки geometric_lib

В данном документе приведено подробное описание всех функций библиотеки, математических формул, типов аргументов и примеров использования в интерактивной консоли Python.

---

## Модуль `circle`

Модуль для работы с круглыми фигурами. Для вычислений используется математическая константа `math.pi`.

### `circle.area(r)`

Вычисляет площадь круга по его радиусу.
* **Формула:** $S = \pi r^2$
* **Параметры:** `r (int | float)` — радиус круга ($r > 0$).
* **Возвращаемое значение:** `float` — площадь круга в квадратных единицах.

```pycon
>>> import circle
>>> round(circle.area(3), 4)
28.2743
```

### `circle.perimeter(r)`

Вычисляет длину окружности (периметр круга) по его радиусу.
* **Формула:** $P = 2 \pi r$
* **Параметры:** `r (int | float)` — радиус круга ($r > 0$).
* **Возвращаемое значение:** `float` — длина окружности.

```pycon
>>> import circle
>>> round(circle.perimeter(3), 4)
18.8496
```

## Модуль `square`

Модуль для вычисления геометрических характеристик квадрата.

### `square.area(a)`

Вычисляет площадь квадрата по длине его стороны.
* **Формула:** $S = a^2$
* **Параметры:** `a (int | float)` — длина стороны квадрата ($a > 0$).
* **Возвращаемое значение:** `int | float` — площадь квадрата.

```pycon
>>> import square
>>> square.area(5)
25
```

### `square.perimeter(a)`

Вычисляет периметр квадрата по длине его стороны.
* **Формула:** $P = 4a$
* **Параметры:** `a (int | float)` — длина стороны квадрата ($a > 0$).
* **Возвращаемое значение:** `int | float` — периметр квадрата.

```pycon
>>> import square
>>> square.perimeter(5)
20
```

## Модуль `rectangle`

Модуль для работы с прямоугольниками.

### `rectangle.area(a, b)`

Вычисляет площадь прямоугольника по двум сторонам.
* **Формула:** $S = a \cdot b$
* **Параметры:** `a, b (int | float)` — длины сторон прямоугольника ($a > 0, b > 0$).
* **Возвращаемое значение:** `int | float` — площадь прямоугольника.

```pycon
>>> import rectangle
>>> rectangle.area(4, 6)
24
```

### `rectangle.perimeter(a, b)`

Вычисляет периметр прямоугольника по двум сторонам.
* **Формула:** $P = 2(a + b)$
* **Параметры:** `a, b (int | float)` — длины сторон прямоугольника ($a > 0, b > 0$).
* **Возвращаемое значение:** `int | float` — периметр прямоугольника.

```pycon
>>> import rectangle
>>> rectangle.perimeter(4, 6)
20
```

## Модуль `triangle`

Модуль для вычисления характеристик треугольника.

### `triangle.area(a, h)`

Вычисляет площадь треугольника по длине основания и высоте, опущенной на это основание.
* **Формула:** $S = \frac{a \cdot h}{2}$
* **Параметры:** `a, h (int | float)` — длина основания и высота ($a > 0, h > 0$).
* **Возвращаемое значение:** `float` — площадь треугольника.

```pycon
>>> import triangle
>>> triangle.area(6, 5)
15.0
```

### `triangle.perimeter(a, b, c)`

Вычисляет периметр треугольника по трем сторонам.
* **Формула:** $P = a + b + c$
* **Параметры:** `a, b, c (int | float)` — стороны существующего треугольника.
* **Возвращаемое значение:** `int | float` — периметр треугольника.

```pycon
>>> import triangle
>>> triangle.perimeter(4, 5, 6)
15
```
