# Геометрическая библиотека (geometric_lib)

Учебный проект по дисциплине **«Инструментальные средства разработки программного обеспечения» (ИСРПО)**, Университет ИТМО.

Библиотека предоставляет набор модулей для расчёта площадей и периметров четырёх геометрических фигур: круга, квадрата, прямоугольника и треугольника.

## Требования к окружению

- Интерпретатор Python 3.
- Библиотека использует исключительно стандартные модули (`math`, `doctest`). Сторонние пакеты не требуются.

## Быстрый запуск

Для работы с библиотекой запустите интерактивную оболочку Python в корневом каталоге проекта:

```python
>>> import rectangle
>>> rectangle.area(4, 6)
24
>>> rectangle.perimeter(4, 6)
20
```

## Проверка примеров документации (doctest)

Каждая функция снабжена исполняемыми примерами в формате `doctest`. Запуск валидации всех примеров из корня проекта:

```console
python -m doctest -v circle.py square.py rectangle.py triangle.py
```

Успешное прохождение тестов подтверждает работоспособность всех примеров вызовов из документации.
